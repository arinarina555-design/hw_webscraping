# Парсер статей Habr

## Описание проекта

Скрипт предназначен для автоматического сбора статей с сайта [Habr](https://habr.com/ru/all/) и поиска публикаций, содержащих заданные ключевые слова.

Поиск осуществляется по информации, доступной на странице со списком статей (preview), а также, в дополнительном режиме, по полному тексту публикаций.

## Установка и запуск


### 1. Установка зависимостей

Установите Selenium:

```bash
pip install selenium
```

### 3. Подготовка браузера

Для работы скрипта необходим установленный браузер Microsoft Edge.

Selenium Manager автоматически определяет и подбирает необходимый драйвер при запуске браузера, поэтому отдельная установка EdgeDriver обычно не требуется.

### 4. Настройка поиска

В начале скрипта можно задать собственные ключевые слова:

```python
KEYWORDS = ['дизайн', 'фото', 'web', 'python']
```

Для переключения режимов поиска используется параметр `FULL_TEXT`:

```python
FULL_TEXT = False
```

Доступны два режима:

- `False` — поиск только по preview-информации статей. Это основной режим выполнения задания.
- `True` — поиск по preview и полному тексту статей. Если ключевое слово уже найдено в preview, повторная проверка полной статьи не выполняется.

### 5. Запуск скрипта

Запустите файл с программой:

```bash
python main.py
```

## Результат работы

Результаты сохраняются в файл `articles.json` в формате JSON.

Пример структуры файла:

```json
[
    {
        "time": "2026-11-13T12:00:00+00:00",
        "title": "Название статьи",
        "link": "https://habr.com/ru/articles/..."
    }
]
```
